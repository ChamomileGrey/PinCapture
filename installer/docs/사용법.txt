핀캡처 (PinCapture) 사용법
==========================

화면을 캡처해서 자동으로 저장하고, 클립보드에 복사하고, 화면 위에 핀으로 고정해 두는 프로그램입니다.
만든 이: 캐모마일그레이 (ChamomileGrey)
설치하면 작업 표시줄 오른쪽 트레이에 상주하며, 어느 프로그램을 쓰고 있든 단축키로 바로 캡처할 수 있습니다.
이 안내는 시작 메뉴의 [핀캡처 사용법]에서 언제든 다시 볼 수 있습니다.


1. 단축키
---------
  Ctrl + Alt + A   영역 지정 캡처 (화면이 멈추면 마우스로 드래그, Esc 또는 우클릭으로 취소)
  Ctrl + Alt + W   창 캡처 (지금 사용 중인 창)
  Ctrl + Alt + F   전체 화면 캡처 (마우스가 있는 모니터)
  Ctrl + Alt + Q   핀 고정 (영역을 지정하면 그 부분이 화면 맨 위에 떠 있음)
  Ctrl + Alt + R   최근 핀 다시 열기 (가장 최근에 닫은 핀)
  Ctrl + Alt + X   클릭 통과 해제 (핀이 마우스 클릭을 받지 않을 때)
  Ctrl + Alt + M   핀 표시 (맨 앞 핀에 화살표·네모·형광펜·모자이크)
  Ctrl + Alt + C   스포이트 (화면 색을 HEX로 복사하고, RGB도 보여 줘요)
  Ctrl + Alt + D   자 (두 점의 픽셀 거리와 가로·세로, 화면 배율을 반영해요)

  단축키는 창의 [설정]에서 바꿀 수 있습니다.
  다른 프로그램과 단축키가 겹치면 동작하지 않을 수 있으니 그때는 다른 조합으로 바꿔 주세요.


2. 기본 사용
------------
  · 영역·창·전체 화면 캡처는 자동으로 파일로 저장되고 클립보드에도 복사됩니다. 바로 붙여넣기(Ctrl+V)할 수 있어요.
  · 핀 고정(Ctrl+Alt+Q) 캡처는 기본적으로 파일로 저장되지 않고 클립보드에만 복사됩니다.
    남겨 두려면 핀을 우클릭 → [다른 이름으로 저장], 또는 설정에서 [핀 캡처도 파일로 저장]을 켜 주세요.
  · 캡처 직후 핀캡처 창이 열리고, 방금 캡처한 이미지가 크게 보입니다.
  · 오른쪽 목록에는 이전 캡처가 쌓입니다. 클릭하면 크게 볼 수 있어요.
    Ctrl/Shift+클릭, 드래그, Ctrl+A 로 여러 개를 한 번에 선택할 수 있습니다.
  · 위쪽 버튼: 클립보드에 복사 / 다른 이름으로 저장 / 화면에 고정 / 저장 폴더 열기 / 목록에서 제거
    (목록에서 제거해도 파일은 지워지지 않습니다.)
  · 캡처 줄 오른쪽의 작은 아이콘: [핀에 그리기] [스포이트] [자] [글자 복사] [최근 핀].
    이름과 단축키는 아이콘에 마우스를 올리면 보여요. 글자 복사에는 단축키가 없어요.
    [핀에 그리기]와 [글자 복사]는 보관함에서 고른 캡처에 적용하고, 고른 것이 없으면 맨 앞 핀에 적용해요.
    캡처도 핀도 없으면 그 두 아이콘은 눌리지 않아요.
    [글자 복사]를 누르면 글자를 문단으로 맞춰 복사해요. 아이콘을 우클릭하면
    글자, 표 (엑셀), 표 (Markdown), 수식 중에서 고를 수 있어요.
  · 처음 실행하면 빠른 안내가 한 번 열려요. 단축키와 핀 사용법이 적혀 있어요.
    나중에 다시 보려면 창의 [안내] 또는 트레이 메뉴의 [빠른 안내]를 누르세요.
  · 창의 [정보] 또는 트레이 메뉴의 [정보]에서 버전, 라이선스, 서드파티 고지를 볼 수 있어요.
  · [후원하기]는 웹 브라우저로 Ko-fi 페이지를 열어요. 후원하지 않아도 기능은 모두 무료예요.
    앱이 일을 방해하는 후원 창을 띄우지는 않아요.
  · 창의 X 버튼을 누르면 트레이로 숨겨지고, 단축키는 계속 동작합니다.
  · 완전히 끄려면: 트레이의 핀캡처 아이콘 우클릭 → [종료]
    (트레이 아이콘이 안 보이면 작업 표시줄 오른쪽 ^ 버튼을 눌러 보세요.)
    종료하면 화면의 핀과 파일로 저장하지 않은 캡처는 사라집니다.

  핀(화면에 고정된 이미지)
  · 드래그로 이동, 마우스 휠로 크기 조절, 더블클릭 또는 Esc 로 닫기
  · Ctrl+휠 로 투명도를 100% / 80% / 60% / 40% 중에서 바꿀 수 있어요. 우클릭 → [투명도]에서도 고릅니다.
  · 우클릭 메뉴: [글자 복사] [클립보드에 복사] [다른 이름으로 저장] [원본 크기]
    [표시] [스포이트] [자] [투명도] [클릭 통과] [닫기]
  · [글자 복사]를 펼치면 [글자] [표 (엑셀)] [표 (Markdown)] [수식]이 나와요.
    [글자]는 Windows에 설치된 한국어·영어 글자 인식으로 핀 안의 글자를 읽어요.
    한 문단 안에서 줄바꿈된 줄은 이어 붙이고, 문단이 나뉜 곳은 빈 줄로 남겨요.
    [표 (엑셀)]은 칸 위치를 맞춰 복사해요. 엑셀에 붙여 넣으면 칸으로 들어가요.
    [표 (Markdown)]은 같은 표를 Markdown으로 복사해요.
    표시가 있어도 글자 인식은 표시 없는 원본을 읽어요.
    언어 팩이나 OCR 구성 요소가 없으면 설치 방법을 안내하고, 캡처 기능은 그대로 쓸 수 있어요.
  · [수식]은 고른 수식을 LaTeX로 복사해요. 용량이 커서 기본 설치에는 들어 있지 않아요.
    처음 고르면 "수식 기능 설치 (약 214MB 다운로드)" 창이 나와요.
    [설치]를 누르면 모델과 실행 구성 요소를 받고, 받은 파일이 맞는지 확인한 뒤 수식을 읽어요.
    [취소]를 누르면 아무것도 받지 않아요. 받는 도중에도 취소할 수 있고, 다음에 설치를 누르면 이어서 받아요.
    Python이나 pip는 필요 없어요. 글자와 표 복사는 설치하지 않아도 그대로 쓸 수 있어요.
    지우려면 설정의 [수식 기능 제거]를 눌러요.
  · [표시]에서 화살표, 네모, 형광펜(반투명), 모자이크를 고르면 핀 옆에 작은 도구가 떠요.
    드래그로 그리고, 색(빨강·노랑·파랑·검정)과 두께(얇게·보통·굵게)는 그 도구에서 골라요.
    Ctrl+Z 는 실행 취소, Ctrl+Y 또는 Ctrl+Shift+Z 는 다시 실행이에요.
    Esc 나 [완료]는 표시만 끝내고 핀은 닫지 않아요. 표시하는 동안에는 핀이 드래그로 움직이지 않아요.
    [클립보드에 복사]와 [다른 이름으로 저장]에는 표시가 들어가요.
    핀을 닫으면 표시는 최근 핀에 남지 않으니, 남기려면 복사하거나 저장해 주세요.
    클릭 통과가 켜져 있으면 표시를 시작할 수 없어요. 먼저 클릭 통과를 꺼 주세요.
  · [스포이트] 또는 Ctrl+Alt+C: 화면이 멈추면 클릭한 색을 #RRGGBB 로 복사하고 RGB도 보여 줘요.
    커서 옆에 확대 돋보기가 나와요. Esc 또는 우클릭으로 취소해요.
  · [자] 또는 Ctrl+Alt+D: 같은 모니터에서 두 점을 클릭하면 물리 픽셀 거리와 가로·세로, 화면 배율을 알려 줘요.
  · [클릭 통과]를 켜면 마우스가 핀 아래의 창으로 전달돼요. 핀을 클릭해서는 끌 수 없으니
    트레이 메뉴 [클릭 통과 해제] 또는 Ctrl+Alt+X 로 꺼 주세요.
  · 닫은 핀은 최근 10개까지 임시로 보관돼요. 트레이 [최근 핀 다시 열기] 또는 Ctrl+Alt+R 로
    가장 최근 것부터 다시 띄울 수 있어요. 개수는 설정의 [닫은 핀 보관 개수]에서 바꿉니다.


3. 저장 위치
------------
  · 기본 저장 폴더: 사진 폴더 안의 PinCapture  (예: C:\Users\이름\Pictures\PinCapture)
  · 설정에서 저장 폴더, 파일 형식(png/jpg), 파일 이름 앞부분을 바꿀 수 있습니다.
  · 사진 폴더가 OneDrive 로 백업되도록 설정된 PC 에서는 캡처도 OneDrive 에 동기화됩니다.
    원하지 않으면 설정에서 저장 폴더를 다른 곳으로 바꿔 주세요.


4. 설치할 때 경고가 뜨면
------------------------
  개인이 만든 무료 프로그램이라 Microsoft 인증서 서명이 없어서 나오는 안내입니다.
  · 브라우저에서 "일반적으로 다운로드되지 않습니다" 경고가 뜨면:
      Edge  : 다운로드 목록의 [⋯] → [유지] → [그래도 계속]
      Chrome: 다운로드 목록에서 [계속] 또는 [유지]
  · 설치 파일을 실행했을 때 파란 "Windows의 PC 보호" 창이 뜨면:
      [추가 정보]를 누른 뒤 [실행]을 누르면 설치가 계속됩니다.
  · Windows 11 에서 "스마트 앱 컨트롤"이 켜져 있는 PC 는 서명 없는 프로그램을 아예 막기 때문에
    지금 버전은 설치할 수 없습니다.


5. 자동 실행
------------
  · 설치할 때 "Windows 시작 시 자동 실행"을 선택하면, 컴퓨터를 켤 때 창 없이 트레이에서 대기합니다.
  · 끄려면: Windows 설정 → [앱] → [시작 프로그램] → 핀캡처 끄기


6. 업데이트와 제거
------------------
  · 업데이트: 새 버전 설치 파일을 실행하면 됩니다. 실행 중인 핀캡처는 자동으로 닫히고 설정은 그대로 유지됩니다.
    (닫힐 때 화면의 핀과 파일로 저장하지 않은 캡처는 사라집니다.)
  · 제거: 시작 메뉴에서 [핀캡처]를 마우스 오른쪽 클릭 → [제거]
      또는 Windows 10: 설정 → 앱 → 앱 및 기능 → 핀캡처 → 제거
           Windows 11: 설정 → 앱 → 설치된 앱 → 핀캡처 오른쪽 [⋯] → 제거
    제거할 때 설정·기록 파일도 지울지 묻습니다. 저장해 둔 캡처 이미지는 지우지 않습니다.


7. 개인정보
-----------
  · 캡처한 이미지는 내 PC 에만 저장됩니다. 평소에는 인터넷에 연결하지 않아요.
    수식 기능의 [설치]를 눌렀을 때만, 모델과 실행 구성 요소를 받아요.
  · 핀캡처가 파일을 만드는 곳:
      저장 폴더                      캡처 이미지
      C:\Users\이름\.pincapture      config.json(설정), pincapture.log(실행 기록),
                                     clipboard\ (여러 캡처를 한 번에 복사할 때 쓰는 임시 이미지)
  · 수식 기능을 설치하면 아래 폴더에 파일이 생겨요. 설정의 [수식 기능 제거]로 지울 수 있어요.
      C:\Users\이름\.pincapture\models\formula   수식 모델
      C:\Users\이름\.pincapture\math             수식 실행 구성 요소
      C:\Users\이름\.pincapture\downloads        받다가 취소했을 때 이어받기용 임시 파일
  · 단축키를 감지하기 위해 키보드 입력을 확인하지만, 입력 내용을 저장하거나 전송하지 않습니다.


8. 문제가 생기면
----------------
  · 캡처하면 화면이 검게만 찍힘 / "화면 캡처가 막혀 있어요" 또는
    "보안 프로그램 때문에 캡처가 막혔을 수 있어요" 안내가 뜸:
    정부24·홈택스·은행 사이트의 전자문서 뷰어나 보안 프로그램이 '화면 캡처 방지'를 켜 둔 상태예요.
    이때는 핀캡처뿐 아니라 다른 캡처 프로그램도 검게 찍힐 수 있어요.
      1) 열려 있는 전자문서 보기 창(예: 정부24 '전자문서 전용 Viewer')을 닫고 다시 캡처
      2) 그래도 안 되면 그 사이트의 브라우저 창도 닫기
      3) 계속되면 컴퓨터를 다시 시작하거나, 설정 → 앱에서 그때 설치된 문서 뷰어(예: ezPDFReader)나
         화면 보안 프로그램(예: WebCube)을 제거
  · 단축키가 안 먹음: 다른 프로그램(카카오톡 등)과 겹치는지 확인하고 설정에서 다른 조합으로 바꿔 주세요.
    관리자 권한으로 실행된 창 위에서는 단축키가 동작하지 않을 수 있습니다.
  · 실행이 안 됨: 백신 프로그램이 핀캡처를 차단했는지 확인하고, 설치 파일로 다시 설치해 주세요.
  · 그래도 안 되면 C:\Users\이름\.pincapture\pincapture.log 파일을 프로그램을 받은 곳(배포한 분)에 보내 주세요.
    (로그의 파일 경로에 Windows 사용자 이름이 들어 있으니, 원하면 보내기 전에 지워 주세요.)


9. 알려진 제한
--------------
  · 스크롤 캡처와, 보관함 이미지를 새 파일로 남기는 편집 창은 아직 없어요.
    핀 위 화살표·네모·형광펜·모자이크는 우클릭 [표시] 또는 Ctrl+Alt+M 으로 그릴 수 있어요.
  · 영역 지정은 모니터 한 대 안에서만 됩니다.
  · 게임 등 전체 화면 전용 프로그램은 검게 캡처될 수 있습니다.
  · Windows 10 / 11 (64비트)에서 동작합니다.
