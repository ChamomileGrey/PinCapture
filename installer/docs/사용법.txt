핀캡처 (PinCapture) 사용법
==========================

화면을 캡처해서 자동으로 저장하고, 클립보드에 복사하고, 화면 위에 핀으로 고정해 두는 프로그램입니다.
설치하면 작업 표시줄 오른쪽 트레이에 상주하며, 어느 프로그램을 쓰고 있든 단축키로 바로 캡처할 수 있습니다.
이 안내는 시작 메뉴의 [핀캡처 사용법]에서 언제든 다시 볼 수 있습니다.


1. 단축키
---------
  Ctrl + Alt + A   영역 지정 캡처 (화면이 멈추면 마우스로 드래그, Esc 또는 우클릭으로 취소)
  Ctrl + Alt + W   창 캡처 (지금 사용 중인 창)
  Ctrl + Alt + F   전체 화면 캡처 (마우스가 있는 모니터)
  Ctrl + Alt + Q   핀 고정 (영역을 지정하면 그 부분이 화면 맨 위에 떠 있음)

  단축키는 설정(톱니 버튼)에서 바꿀 수 있습니다.
  다른 프로그램과 단축키가 겹치면 동작하지 않을 수 있으니 그때는 다른 조합으로 바꿔 주세요.


2. 기본 사용
------------
  · 영역·창·전체 화면 캡처는 자동으로 파일로 저장되고 클립보드에도 복사됩니다. 바로 붙여넣기(Ctrl+V)할 수 있어요.
  · 핀 고정(Ctrl+Alt+Q) 캡처는 기본적으로 파일로 저장되지 않고 클립보드에만 복사됩니다.
    남겨 두려면 핀을 우클릭 → [다른 이름으로 저장], 또는 설정에서 [핀 캡처도 파일로 저장]을 켜 주세요.
  · 캡처 직후 핀캡처 창이 열리고, 방금 캡처한 이미지가 크게 보입니다.
  · 오른쪽 목록에는 이전 캡처가 쌓입니다. 클릭하면 크게 볼 수 있어요.
    Ctrl/Shift+클릭, 드래그, Ctrl+A 로 여러 개를 한 번에 선택할 수 있습니다.
  · 위쪽 버튼: 클립보드 복사 / 다른 이름으로 저장 / 핀 고정 / 저장 폴더 열기 / 목록에서 제거
    (목록에서 제거해도 파일은 지워지지 않습니다.)
  · 창의 X 버튼을 누르면 트레이로 숨겨지고, 단축키는 계속 동작합니다.
  · 완전히 끄려면: 트레이의 핀캡처 아이콘 우클릭 → [종료]
    (트레이 아이콘이 안 보이면 작업 표시줄 오른쪽 ^ 버튼을 눌러 보세요.)
    종료하면 화면의 핀과 파일로 저장하지 않은 캡처는 사라집니다.

  핀(화면에 고정된 이미지)
  · 드래그로 이동, 마우스 휠로 크기 조절, 우클릭으로 메뉴(복사/저장/원래 크기), 더블클릭 또는 Esc 로 닫기


3. 저장 위치
------------
  · 기본 저장 폴더: 사진 폴더 안의 PinCapture  (예: C:\Users\이름\Pictures\PinCapture)
  · 설정에서 저장 폴더, 파일 형식(png/jpg), 파일 이름 앞부분을 바꿀 수 있습니다.
  · 사진 폴더가 OneDrive 로 백업되도록 설정된 PC 에서는 캡처도 OneDrive 에 동기화됩니다.
    원하지 않으면 설정에서 저장 폴더를 다른 곳으로 바꿔 주세요.


4. 설치할 때 경고가 뜨면
------------------------
  개인이 만든 무료 프로그램이라 Microsoft 인증서 서명이 없어서 나오는 안내입니다.
  · 브라우저에서 "일반적으로 다운로드되지 않습니다" 경고가 뜨면:
      Edge  : 다운로드 목록의 [⋯] → [유지] → [그래도 계속]
      Chrome: 다운로드 목록에서 [계속] 또는 [유지]
  · 설치 파일을 실행했을 때 파란 "Windows의 PC 보호" 창이 뜨면:
      [추가 정보]를 누른 뒤 [실행]을 누르면 설치가 계속됩니다.
  · Windows 11 에서 "스마트 앱 컨트롤"이 켜져 있는 PC 는 서명 없는 프로그램을 아예 막기 때문에
    지금 버전은 설치할 수 없습니다.


5. 자동 실행
------------
  · 설치할 때 "Windows 시작 시 자동 실행"을 선택하면, 컴퓨터를 켤 때 창 없이 트레이에서 대기합니다.
  · 끄려면: Windows 설정 → [앱] → [시작 프로그램] → 핀캡처 끄기


6. 업데이트와 제거
------------------
  · 업데이트: 새 버전 설치 파일을 실행하면 됩니다. 실행 중인 핀캡처는 자동으로 닫히고 설정은 그대로 유지됩니다.
    (닫힐 때 화면의 핀과 파일로 저장하지 않은 캡처는 사라집니다.)
  · 제거: 시작 메뉴에서 [핀캡처]를 마우스 오른쪽 클릭 → [제거]
      또는 Windows 10: 설정 → 앱 → 앱 및 기능 → 핀캡처 → 제거
           Windows 11: 설정 → 앱 → 설치된 앱 → 핀캡처 오른쪽 [⋯] → 제거
    제거할 때 설정·기록 파일도 지울지 묻습니다. 저장해 둔 캡처 이미지는 지우지 않습니다.


7. 개인정보
-----------
  · 핀캡처는 인터넷에 연결하지 않습니다. 캡처한 이미지는 내 PC 에만 저장됩니다.
  · 핀캡처가 파일을 만드는 곳:
      저장 폴더                      캡처 이미지
      C:\Users\이름\.pincapture      config.json(설정), pincapture.log(실행 기록),
                                     clipboard\ (여러 캡처를 한 번에 복사할 때 쓰는 임시 이미지)
  · 단축키를 감지하기 위해 키보드 입력을 확인하지만, 입력 내용을 저장하거나 전송하지 않습니다.


8. 문제가 생기면
----------------
  · 캡처하면 화면이 검게만 찍힘 / "화면 캡처가 막혀 있어요" 안내가 뜸:
    정부24·홈택스·은행 사이트의 전자문서 뷰어나 보안 프로그램이 '화면 캡처 방지'를 켜 둔 상태예요.
    이때는 핀캡처뿐 아니라 다른 캡처 프로그램도 검게 찍힐 수 있어요.
      1) 열려 있는 전자문서 보기 창(예: 정부24 '전자문서 전용 Viewer')을 닫고 다시 캡처
      2) 그래도 안 되면 그 사이트의 브라우저 창도 닫기
      3) 계속되면 컴퓨터를 다시 시작하거나, 설정 → 앱에서 그때 설치된 문서 뷰어(예: ezPDFReader)나
         화면 보안 프로그램(예: WebCube)을 제거
  · 단축키가 안 먹음: 다른 프로그램(카카오톡 등)과 겹치는지 확인하고 설정에서 다른 조합으로 바꿔 주세요.
    관리자 권한으로 실행된 창 위에서는 단축키가 동작하지 않을 수 있습니다.
  · 실행이 안 됨: 백신 프로그램이 핀캡처를 차단했는지 확인하고, 설치 파일로 다시 설치해 주세요.
  · 그래도 안 되면 C:\Users\이름\.pincapture\pincapture.log 파일을 프로그램을 받은 곳(배포한 분)에 보내 주세요.


9. 알려진 제한
--------------
  · 스크롤 캡처, 캡처 후 그림 그리기(편집)는 아직 없습니다.
  · 영역 지정은 모니터 한 대 안에서만 됩니다.
  · 게임 등 전체 화면 전용 프로그램은 검게 캡처될 수 있습니다.
  · Windows 10 / 11 (64비트)에서 동작합니다.
