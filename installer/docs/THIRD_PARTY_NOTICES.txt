8. Optional formula-to-LaTeX pack  (NOT included in the installer)
   수식 mode can turn a captured formula into LaTeX. The base installer does not ship
   the model or the runtime. Text and table copy work without them.
   The app downloads PinCapture-Math-<version>.zip only after the user clicks 설치,
   checks its SHA-256, and checks the model and tokenizer hashes inside the zip.
   Cancelling leaves a partial file so the next 설치 can resume. 설정 can remove the files.

   The zip is a GitHub release asset built by installer/build_math_pack.py.
   It contains PP-FormulaNet_plus-S (about 233 MB) plus the Windows runtime below.

   PP-FormulaNet_plus-S  (PaddlePaddle)
   License : Apache License 2.0  — licenses\Apache-2.0.txt

   conversion published with RapidAI RapidDoc:
   https://www.modelscope.cn/models/RapidAI/RapidDoc
   PinCapture does not bundle RapidDoc or PaddleX. The image preprocess lives in pincapture.py.

   pix2tex / LaTeX-OCR weights are NOT used. Those weights are CC BY-NC-SA and are not
